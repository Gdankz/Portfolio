# Gabriel Bayu — Portfolio

Personal portfolio of Gabriel Bayu — IoT & Backend developer.
Live single-page site with dark/light theme, animated starry background, skills, projects, and contact section.

Built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS v4**.

## Scripts

| Command           | Description                    |
| ----------------- | ------------------------------ |
| `npm run dev`     | Start dev server               |
| `npm run build`   | Type-check and build for prod  |
| `npm run preview` | Preview the production build   |
| `npm run lint`    | Run ESLint                     |
| `npm test`        | Run unit tests (Vitest)        |

## Structure

```
src/
├── assets/        # Images (hero photo)
├── components/    # UI sections and widgets
├── lib/           # Utilities (cn)
├── pages/         # Route pages (Home, NotFound)
└── test/          # Test setup
```
